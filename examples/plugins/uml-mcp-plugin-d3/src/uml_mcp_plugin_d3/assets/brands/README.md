# Bundled brand logos

Brand artwork from [@lobehub/icons-static-svg](https://www.npmjs.com/package/@lobehub/icons-static-svg)
1.101.0 (MIT, see [lobehub/lobe-icons](https://github.com/lobehub/lobe-icons)). Brand names and logos
remain trademarks of their respective owners; these icons identify diagram components and do not
imply endorsement.

The files ship inside the package, so they render the same locally, in Docker and on the hosted
servers, with no request to an icon CDN at render time. Each SVG was checked when it was added (no
scripts, event handlers, entities or external references), and `tests/test_plugin_d3_logos.py` checks
them again on every run. The D3, stack-diagram and archify plugins all draw from this set.
